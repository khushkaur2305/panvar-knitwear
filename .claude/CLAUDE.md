# K.K. Knitwear Club – Website Project

## Reference Website

**Existing Website:** https://www.kkknitwearclub.com/

Use the existing website as the main reference for the company's content, products, categories, specifications, images, contact information and important functionality.

## Project Overview

Create a **modern, premium and professional B2B website** for **K.K. Knitwear Club, Ludhiana**, a manufacturer and supplier of polyester and knitted fabrics.

The website should showcase the company's products, manufacturing capabilities and expertise while helping business customers make enquiries and request quotations.

## Target Audience

* Garment manufacturers
* Clothing brands
* Wholesalers and retailers
* Exporters
* Bulk fabric buyers

This is a **B2B textile website**, not a normal fashion store or ecommerce website.

## Main User Journey

**Explore Fabrics → View Details → Build Trust → Enquire → Get Quote**

## Required Sections

* Home
* About Us
* Products / Fabric Catalogue
* Manufacturing & Infrastructure
* Gallery
* Testimonials
* Contact Us
* Request a Quote

## Product Experience

Include:

* Product categories
* Product search and filtering
* Attractive product cards
* Product images
* Material
* GSM
* Width
* MOQ
* Applications
* Other available specifications
* Request Quote / Get Best Price

## Design Direction

Create a **premium textile-industry aesthetic** with:

* Clean and spacious layouts
* Strong visual hierarchy
* Professional typography
* High-quality fabric and manufacturing imagery
* Modern cards and buttons
* Subtle textile-inspired textures
* Smooth hover effects and transitions
* Tasteful animations
* Limited and meaningful 3D/visual elements
* Excellent desktop and mobile responsiveness

Avoid a generic template, outdated corporate appearance, excessive animations, or consumer ecommerce styling.

## Technology

Build the frontend using:

**HTML5 + CSS3 + JavaScript (ES6+)**

Use:

* Semantic HTML
* CSS Grid and Flexbox
* Responsive CSS
* Modern animations and transitions
* Reusable JavaScript functions/components
* Clean and organized code

Keep the website **fast, responsive, accessible and easy to maintain**.

## Content Rule

Use the existing K.K. Knitwear Club website as the **source of truth**.

Do not invent company information, products, specifications or other business details.

## Final Goal

The website should immediately communicate:

**Who they are → What they manufacture → Who they serve → Why choose them → How to enquire**

The final design should feel **professional, trustworthy, premium and client-ready**.
